# Spaz SsG Admin iOS Companion App

Standalone React Native / Expo iOS application designed to manage the official Spaz SsG website remotely from your iPhone.

## Features
- **Secure Authentication**: Username & password login backed by Expo SecureStore and Face ID / biometric unlock.
- **Music Release Management**: Add and delete music releases instantly.
- **Announcements**: Manage live broadcast announcements.
- **Settings**: Configure artist name and website tagline ("No Sleep, Just Dreams").
- **Official Branding**: Dark-mode styling matching the Spaz SsG color palette (Electric Cyan `#00DDF5`, Warm Orange `#FF791D`, Silver `#D9DDE2`, Near Black `#08090C`).

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npx expo start --ios
   ```
3. Sign in using your administrator credentials (`admin` / `spazssg2026`).
